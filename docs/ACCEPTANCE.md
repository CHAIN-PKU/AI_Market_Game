# 验收说明（大白话）

## 现在到底实现了什么？

**一句话：** 在电脑里跑一个「双文明抢单打工 + 赚钱买技能」的**自动沙盘**，还没有游戏画面。

| 你期待的 | 当前状态 |
|----------|----------|
| 浏览器里点按钮、看地图 | ❌ 还没做（Phase 4） |
| 每个居民是谁、在干嘛 | ✅ 用 `sim:agents` 在终端逐轮看 |
| Cursor 里多个大模型实时对话 | ❌ 不是这个；居民是 **Mock 规则 AI**（以后可接 LLM） |
| 两种经济制度对比 | ✅ A 自由市场 vs B 公共研发 |
| 买 Skill 后变强 | ✅ Skill 会加能力，影响接单成功率 |
| 30 轮跑完不崩、钱不为负 | ✅ `npm test` |

## 三个命令分别证明什么？

### 1. `npm test`

**证明：** 引擎规则没写崩（不能负余额、同 seed 结果一样、不会重复发奖）。

### 2. `npm run sim:dual`

**证明：** 30 轮里两个文明**都在**参与经济（两边都有产出/成败），制度参数真的挂在不同文明上。

**你应该看到：** 每隔 5 轮有两行文明汇总；结尾 A、B 都有 `总产出 > 0`（修平衡后），且数字、Skill 次数不会完全一样。

### 3. `npm run sim:agents -- --rounds 6`

**证明：** 每个居民在每一轮有具体动作（接到什么单、成败、谁买了 Skill、钱包和能力数字）。

**你应该看到：** 每轮一节「居民在干什么」+ 8 人状态表；钱包和 C/R/D 能力会随轮次变化。

## Step：本地网页 + 真实 LLM（可选）

**做了什么：** HTTP 后端驱动同一套模拟器；浏览器里点「下一步」看居民抢单；配置 Key 后前 2 名居民走真实 Chat API。

| 验收 | 命令 / 操作 | 成功标准 |
|------|-------------|----------|
| 全测试 | `npm run test:all` | simulation + server 全绿 |
| 启动 | 终端1 `npm run dev:server` 终端2 `npm run dev:web` 或根目录 `npm run dev` | 无报错 |
| 打开 UI | 浏览器 **http://127.0.0.1:5173**（仅 HTTP 本地） | 见双文明面板 + 纪事 |
| 交互 | 点「下一步」 | 轮次 +1，纪事出现抢单/完成，居民钱包变化 |
| Live AI | 复制 `.env.example` → `.env`，填 `OPENAI_API_KEY`，`AI_CIV_AGENT_MODE=hybrid`，重启 server | 顶栏显示 Live AI；居民卡片出现绿色「Live LLM」和一句 reasoning |
