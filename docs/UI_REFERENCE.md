# UI 参考（开源叙事 / 文字游戏）

实现时借鉴的布局思路（未直接拷贝代码）：

- [react-text-game](https://github.com/laruss/react-text-game/) —  passage 摘要 + 展开、语义色、心流式阅读
- [NarraLeaf React](https://github.com/NarraLeaf/narraleaf-react) — 角色条 + 对话气泡
- [react-story-rich](https://github.com/wasa42/react-story-rich) — 时间线与节点导航

本项目对应：

- **主屏** = 单 passage 摘要（故事卡 + PK）
- **剧场** = 分节 + 展开细节
- **心路** = 角色对话气泡（reasoning）
- **前行导览** = 多步 passage 向导
