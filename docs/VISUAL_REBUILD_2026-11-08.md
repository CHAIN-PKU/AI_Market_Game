# 2.5D 视觉重塑 — 第一版

> 回应「像素低、有色块、人物和建筑都丑」：先把场景从 Kenney 盒子 + 纯色块换成自定义小屋、材质和道具；人物仍是 Quaternius chibi，这一版先解决清晰度与场景丰富度。

## 1. 这次改了什么

### 渲染清晰度

- 高画质 DPR 从 `1.5–2` 提到 `2.5–3`，中画质 `1.5–2`，低画质 `1–1.5`。
- 色调映射从 ACES 换成 Neutral，减少灰蒙和色块压缩；曝光 1.0。
- toon ramp 从 3 阶改为 5 阶，角色阴影带更细。
- 保留 antialias；Canvas 饱和度/对比度轻调；不再用 Bloom/EffectComposer（此前 1366/2560 会白屏）。

### 建筑

7 栋楼全部改为程序化 **CozyBuilding**：

- 石基、灰泥墙、木梁、坡屋顶、分层瓦片、屋脊
- 门、门廊条纹雨棚、窗户、窗框、花箱、招牌
- 烟囱 + 烟雾
- 角色专属屋顶装饰：程序坊天线、研究所玻璃穹顶、设计屋调色板、市集旗、技能铺发光牌、公研仓旗杆
- 建筑颜色按角色区分：市集青绿、技能紫、程序坊深青、研究所蓝、设计屋橘、公研仓金、居民里绿

### 环境

- 草地/广场改为 Canvas 程序纹理（草叶、土斑、石板缝）。
- 新增 34 组花、14 丛灌木、46 丛草、4 盏路灯、2 张长椅、云朵。
- 岛缘泡沫环、水面高光。
- 市集建筑移到公告板左侧，避免被公告板完全挡住。

### 人物

- 保留 Quaternius 身体与 idle/walk 动画。
- 脸部 overlay 重做：棕色虹膜、高光、上眼线、眉毛、鼻子、腮红、微笑；去掉之前的黑点眼。
- 头发/肤色仍按角色变化。

## 2. 参考方向

- **Genshin**：暖色主光 + 冷色补光、轮廓清晰、角色特写。
- **Cozy Grove / Animal Crossing**：低饱和暖色、圆润屋顶、花箱和路灯。
- **Dorfromantik / Islanders**：桌面微缩岛、建筑围绕中心广场。
- 不使用任何参考游戏的素材；建筑和纹理全部程序化。

## 4. 诚实边界

- 人物仍是 Quaternius 低模 chibi，不是原神级角色；这一版只把脸做得不那么“点眼睛”。
- 建筑是程序化 low-poly，不是手工建模；近看仍能看到几何边。
- 1366 下左右两端建筑会被 HUD 遮住一部分，镜头没有为窄屏重新构图。
- 没有 Bloom/DOF/SSAO；之前的后处理会让部分分辨率白屏。
- 下一步若要真正“好看”，需要换一套更精细的角色资产或做自定义 chibi 建模，而不是继续调低模材质。
