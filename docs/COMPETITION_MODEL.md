# 竞争博弈 v2 — 成本、利润、声誉、对手压力

## 旧模型的问题

旧版只算：

```
赢家 = max(预期质量 × 报价)
```

结果像“参数比较”，不像真人竞争：

- 没有成本，报价可以低到不真实
- 没有利润，赢家可能做亏本单
- 没有声誉，做过多少单不影响下一单
- 没有对手压力，报价不会因为同行多而变狠
- 没有分工，所有人对所有任务用同一套逻辑

## v2 新增

在 `MockAgentDecisionProvider({ marketDepth: true })` 下：

### 1. 预估成本

```
cost = reward × (0.30 + (1-quality)×0.15 + (1-probability)×0.05)
```

### 2. 预计利润

```
profit = quality × reward - cost
```

只有 `profit >= 1` 才进入候选；报价下限被抬到 `cost + 4`，避免明显亏本报单。

### 3. 履约声誉

```
reputation = (completed + 1) / (completed + failed + 3)
```

声誉带来小幅溢价；做过单的人不必用最低价抢。

### 4. 对手压力

```
pressure = min(0.12, strongerSpecialists × 0.025)
bidFactor = base - pressure + reputationPremium
```

同域比自己强的人越多，报价越往下压——价格战。

### 5. 玩家任务优先

玩家发布的 task 在排序时有 1.25× 价值权重，避免 3 个系统任务把玩家任务完全挤掉；这是演示层的可见性修正，不是经济补贴。

### 6. 组队投标

有钱一起赚，但钱要分：

- 找一个同域能力最强的可竞标伙伴
- 联合成功率用 `max(lead, partner) + 0.25 × min(lead, partner)`
- 组队报价通常更低、质量更高，但中标后 **70/30 分账**
- 队伍成员共享产能约束：一个人在同一轮只能接一单
- 首屏 fixture 里 Delta + Astra 组队中标，净收入 64，二人分账

### 7. 产能 / 档期

- 任务可以带 `durationRounds`（设计轮的任务是 2 轮）
- 中标后所有队员写入 `busyUntilRound = round + duration`
- 忙碌期间不参与新报价；任务在下一轮才结算
- 一人一轮最多 1 单，队伍成员共享这个限制
- 结算/失败会清空档期

这使“忙不过来”成为真实约束，而不是一句文案。

### 8. 赢家诅咒

如果报价低于成本线，会被 `cost + 4` 下限拦住；中标后利润为负的情况不会出现在正常报价里。

## UI 里能看到

人物设定卡 / 决策卡新增：

- 预估成本
- 预计利润
- 履约声誉
- 同域对手

首屏 fixture 已用 `marketDepth: true` 重新生成；5 轮 campaign 也走 rich provider。

### 9. 价格联盟 / 串标

高合作倾向的人会形成价格联盟：

- 选一个联盟 leader 正常报价
- 伙伴即使能接，也以「价格联盟」为由放弃
- leader 中标后，从自己净收入里给伙伴 **5% 抽成**
- 伙伴的放弃让市场上少了竞标者，成交价更容易被抬高
- 事件流会写「串标 / 分钱」

联盟并不稳定：成员可以 **背叛**，自己报低价抢单。首屏 fixture 里 Delta 打上「背叛」标签，市场从 2 个有效报价回到 3 个；联盟的抑制效果被打破。

背叛会被联盟举报：`ringDefections` +1，声誉公式里按 2 倍失败惩罚；下一轮报价和胜率都会变差。

## 制度对比卡

改规则后会并排比较：

- 中标人 / 到手
- 技能购买
- **报价人数 / 价差**
- **组队数**
- **串标数 / 举报数**

同一批居民，税率从 8% 调到 25% 时，首屏示例从 3 人报价、1 个组队变成 2 人报价、0 个组队；到手从 64 变 75。

## 5 轮聚合

编年史会把每轮的：

- 组队数
- 串标 / 举报数
- 平均报价人数

累加成文明层面的指标。实测 5 轮：组队 5 次、串标 4 次、举报 3 次、平均报价 3 人。

## 双文明 5 轮对抗

`/api/experiment` 会创建两个文明（自由市场 vs 高税/公共研发），让 16 个居民在同一市场抢单，跑 5 轮，返回：

- 总到手 / 总税
- 平均中标价
- 组队 / 串标 / 举报
- 买技能 / 唯一赢家
- 基尼

改规则面板里点「跑 5 轮 A/B」即可并排看；两个文明共享任务市场，能直接比较跨文明抢单结果；报告可「存成图片」。

示例（seed 1）：
- 自由市场：总到手 165，税 15，基尼 0.672
- 高税再分配：总到手 135，税 46，基尼 0.747

## 策略标签

居民在报价/设定卡里显示策略：

- 激进抢单（高风险偏好）
- 合作优先（高合作倾向）
- 稳健报价（其余）

策略不是纯文案：风险偏好已影响安全线和报价，合作倾向已影响联盟/组队。

## 还没有做

- **拍卖形式**：仍是质量×价格评分，不是英式/荷式/第二价格
- **学习**：声誉影响报价，但不改变能力
- **组队范围**：目前只对玩家发布的高难度任务开放，系统任务还没有组队

这些是后续要补的“真人竞争”层。
