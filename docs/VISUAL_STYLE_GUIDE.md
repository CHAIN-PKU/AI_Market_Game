# 视觉风格规范 — AI Market Game

## 2. 调色板

| 用途 | 色 |
|------|-----|
| 天空 | `#F5F8FC` → `#B8D4E8` 渐变 |
| 草地 | `#7CBF7A`（低饱和鲜绿） |
| 道路/木 | `#C49A6C` / `#8B5E3C` |
| 建筑主体 | 奶油白 `#F5F0E6`、浅黄 `#F2D98A`、浅青 `#A8DADC`、砖红 `#D4846A` |
| 科技点缀 | 青蓝 `#4EA8DE`、柔紫 `#9B8FD9` |
| 金币 | 琥珀金 `#F4B942` |
| 正文 | 深蓝灰 `#2C3E50` |

**禁止：** 大面积纯黑、霓虹蓝紫赛博、满屏表格、十几个同步浮窗。

---

## 3. 空间与光照

- 地形有 **厚度**（台阶/地块边缘），非单色平面  
- 明确 **主光**（左上 45°），柔和阴影 `softShadowMap`  
- 背景简洁（天空 dome 或淡渐变），不抢主城  
- 建筑 **接地** + contact shadow；禁止角色浮空/穿模（验收项）

---

## 4. 建筑 Silhouette（无文字也应可猜）

| 建筑 | 视觉语言 |
|------|----------|
| 任务市场 | 开放广场 + 招牌 + 任务旗 |
| Skill 商店 | 橱窗 + 芯片/卡牌符号 |
| Coding 工坊 | 屏幕/服务器块 + 冷色点缀 |
| Research 中心 | 圆顶/天线/烧瓶形装饰 |
| Design 工坊 | 斜顶 + 画板/色卡 |
| 公共研发中心 | 更大体量 + 共享标志 |

Walking Skeleton 可用程序化 mesh；**验收前**需替换或精修 CC0 包内模型。

---

## 5. Agent 角色

- 统一骨骼比例；**头+躯干+四肢**  
- 职业附件：Coding 背包/工具、Research 眼镜/书、Design 围巾/板、Business 公文包  
- 动画：idle、walk（切片 P0 可简化）；选中 outline 或 bounce  
- **禁止：** 同色球体排成一排

---

## 6. UI 组件

- 顶：资源条（药丸形容器）  
- 底：木质感或羊皮纸色控制条  
- 面板：圆角 12–16px、轻阴影、可收起  
- 图标：Lucide 仅用于非世界观功能（设置、音量）  
- 世界观内图标：金币、Skill 卡自定 sprite

---

## 7. 动画与因果

动画 **仅由 Event Playback 队列** 触发；类型映射见 `EVENT_CONTRACT.md`。

---

## 8. 性能档位

| 档位 | 行为 |
|------|------|
| 标准 | 阴影 on，DPR = device |
| 低 | DPR≤1，无阴影，无粒子 |

---

## 9. 素材来源原则

- Kenney.nl、Quaternius（CC0）优先；清单见 `packages/web/public/assets/assets-manifest.json`  
- 禁止未授权商业游戏资产  
- 程序化占位 = `procedural-placeholder` license 字段
