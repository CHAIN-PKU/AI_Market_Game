# 大白话 UI 改造 — 对齐最早的产品目标

> 2026-11-08 · 回应「界面简短大白话一点，继续对齐最早的提示词目标」

---

## 1. 最早的目标（这次重贴到界面上）

> **玩家设计规则，AI 自己创造历史。**
> 玩家不是每个 AI 的老板，而是制度设计师；AI 自主接单、赚钱、消费投资、能力进化，再进入下一次竞争。

所以首屏现在直接写：

> **你是制度设计师**
> 改规则，看 8 个 AI 自己接单、赚钱、买技能、变强。

首屏卡片带三步提示（发任务 / 看 AI 抢单 / 改规则）和「先看一轮」按钮，只在任务未发布时出现。

## 2. 文案对照（旧 → 新）

| 位置 | 旧 | 新 |
|---|---|---|
| 顶栏 | 制度实验 | 改规则 |
| 顶栏 | 开 5 轮文明 | 看 5 轮 |
| 顶栏 | 下一轮 | 再来一轮 |
| 顶栏 | 再开 5 轮 | 再跑 5 轮 |
| 左栏 | 主任务 | 今天这单 |
| 左栏 | 竞标名单 | 谁想接 |
| 左栏 | 观望 | 不接 |
| 左栏 | 任务奖励 / 税金 / 实际入国库 | 这单收入 / 税 / 国库实际多了 |
| 右栏 | 公开决策记录 | 它怎么想的 |
| 右栏 | 风险安全线 / 风险调整价值 | 它要求 / 这单值 |
| 右栏 | 性格参数（影响决策） | 它的性格 |
| 右栏 | 投资倾向 / 合作偏好 | 爱花钱吗（合作偏好暂时移除） |
| 右栏 | 当前目标 / 能力 / 公开履历 | 现在想要 / 本事 / 过往成绩 |
| 规则面板 | 制度实验台 / 公共研发份额 / 技能归属 / 随机种子 | 改规则，看变化 / 税里拿多少做公共研发 / 技能归谁 / 换一批任务 |
| 规则按钮 | 用这套制度重跑 | 用这套规则再跑一轮 |
| 编年史 | 文明编年史 / 累计税 / 已记录 | 这 5 轮发生了什么 / 税钱 / 跑了 |
| 事件抽屉 | 本轮事件记录 / task_posted | 这一轮发生了什么 / 发任务；英文 message 也改成中文短句 |

同时：

- 右侧「合作偏好」暂时移除（当前引擎没有合作机制，先不占注意力）。
- 决策因子从 5–6 个压到 4 个：有把握 / 它要求 / 这单值 / 钱包；目标单独用「想要」。
- 每轮状态从「成功率/风险安全线」改成「有把握/它要求」，先让玩家看懂为什么接/不接。

## 4. 边界

- 开发者面板仍保留技术字段，但玩家默认看不到。
- 只改了文案/信息层级，不改经济、竞价、结算、技能价格。
- 「制度」「文明」这些概念保留，因为它们是产品核心；没有把它们改成无意义的词。
- 视觉仍是低模 + 卡通渲染，不是原神 1:1。
