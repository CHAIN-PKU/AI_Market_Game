# 启动与重新开始

## 一条命令（推荐）

```powershell
cd D:\AICivilization
npm run dev
```

浏览器打开：**http://127.0.0.1:5173**

## 完全重新开始一局

1. 浏览器里点 **「新局」**
2. 或强刷页面 **Ctrl + F5**（会新建对局）
3. 若改过代码：终端 **Ctrl+C** 停掉 `npm run dev`，再执行一次 `npm run dev`

## 推理流式输出（Cursor 模式）

- 点「开启第 1 天 / 下一回合」出现等待层时，会 **SSE 连接** `/api/games/<id>/mind`，按 **文明**（两座）展示模型逐字输出（中间过程）。
- 回合结束后，每人一句 **决议台词** 仍在底部 **「心路」** 抽屉（来自 JSON 里的 `reasoning`）。  
  当前架构是「每文明一次 Cursor 调用，统筹 8 人报价」，不是 8 个独立 Agent 同时各跑一条流（那会大幅增加耗时与费用）。

## 像「卡死」时怎么判断

- **正常**：`npm run dev` 终端里先出现 `[game] round advance start`，再等 Cursor；每座文明一次 `Agent.create+send`（**Cursor 模式下串行**：A 完成再 B），默认 **每文明最多约 120 秒**（`AI_CIV_CURSOR_TIMEOUT_MS`）。本地 Agent 在出第一个字前可能静默 1～3 分钟；界面有心跳提示。前端 `POST /advance` 超时见 `/api/meta` 的 `advancePostTimeoutMs`。
- **真挂了**：超时会在界面报错，终端有 `超时`；若完全没有 `[cursor] Agent.create+send start`，说明请求没进后端（端口 / 单进程 dev / 旧 gameId）。
- **改代码后 server 重启**：对局在内存里会丢，前端会提示「自动新建」；请只开一个 `npm run dev`，避免 3001 占端口。

## 端口

| 地址 | 用途 |
|------|------|
| **5173** | 玩游戏 |
| 3001 | 后端 API（不要当主页面） |

## 界面（简洁版）

- **首次**：5 步前行导览 → 筹备屏 → **开启第 1 天**（不是一上来就「下一回合」）
- **第 1 天结束后**：4 步「认界面」再显示故事卡 / PK
- 帮助里可 **重新播放前行导览**
- 主屏中间深色「本回合」卡片：点一下进剧场
- 底部：**规则 | 发任务 | 剧场**（侧边抽屉）
- 点 **文明 A / B** 卡片 → 居民列表 → 再点某人看详情
