# 视觉规范 v1（第二关入口）

> 审查要求：不要只做局部 CSS 美化，先给一份精简的视觉规范，明确主色板、字体、字号体系、
> 卡片与对话框、按钮与交互状态、角色头像、任务卡、政策卡、资源栏、经济结果展示。
> 风格目标：**Cozy Low-poly Strategy Game · 温暖轻科幻 · 有经济文明世界观 · 少量桌游与 RPG 元素**。
> 参考作品的**界面原则**（不复制素材）：Against the Storm 的经营信息层级、Wildermyth 的角色事件表现、
> Civilization VI 的政策选择呈现。

---

## 1. 主色板（沿用现有令牌，不推翻）

| 用途 | 令牌 | 值 | 说明 |
|------|------|----|------|
| 页面底 | `--g-page` | `#f4ecdd` | 暖米色，所有面板浮在它上面 |
| 面板/卡片 | `--g-panel` | `#fffaf0` | 比页面亮一档，形成"纸片"层次 |
| 卡片内衬 | `--surface-card` | `#f6efdf` | 行、格、小块的底 |
| 深色强调 | `--surface-strong` | `#1d1a16` | 数字卡、心流气泡、关键结论 |
| 主文字 | `--g-ink` | `#233733` | 墨绿，比纯黑柔和 |
| 次文字 | `--g-muted` | `#6e8078` | 说明、单位 |
| 弱文字 | `--text-3` | `#8a7a5f` | 标签、脚注 |
| 金（钱） | `--g-gold` / `-deep` | `#e0a94f` / `#b8842f` | 金币、奖励、溢价 |
| 青（中立/系统） | `--g-teal` / `-deep` | `#3f8f96` / `#2f6f75` | 选中态、进度 |
| 珊瑚（风险/背叛） | `--g-coral` | `#d97a52` | 失败、背叛、警示 |
| 绿（成长） | `--g-grass` | `#7cbf7a` | 能力提升、做成 |
| 紫（研究） | `--g-violet` | `#8f7cc9` | 研究域、公共研发 |

**纪律**：新增颜色必须先进令牌表；禁止在规则里直接写十六进制（现有代码里还有约 20 处待清理）。

---

## 2. 字体与字号

| 角色 | 字体 | 字号 | 用途 |
|------|------|------|------|
| UI 正文 | `--font-ui`（苹方/冬青黑/雅黑） | `--fs-12` / `--fs-13` | 面板正文、说明 |
| 标题 | 同上，700 | `--fs-18` / `--fs-22` / `--fs-28` | 面板标题、区块标题 |
| 数字 | `--font-data`（等宽）+ `tabular-nums` | `--fs-18` / `--fs-22` / `--fs-36` | 金额、能力、成功率 |
| 标签 | `--font-ui`，大写/加字距 | `--fs-11` + `--tracking-label` | ① 中标 / 领域 / 口径 |

**纪律**：数字一律等宽 + tabular；正文最小 12.5px；不用 10px 以下做正文。

---

## 3. 卡片与对话框

- **卡片**：2px 描边（`--edge`）+ 硬阴影（`--shadow-hard`）+ 8/12/16 圆角；
  内衬 `--surface-card`，只放"同一件事的一行"
- **对话框**：宽 720–760，四段结构 = 标题区 / 内容区 / 结论条 / 底部按钮
- **禁止**：卡片里再套卡片超过两层

---

## 4. 按钮与状态

| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 | 深色底 + 白字（`--surface-strong`） | 先看一轮 / 下一轮 / 再跑一轮 |
| 次按钮 | 米色底 + 描边 | 改规则 / 看 5 轮 |
| 轻按钮 | 无描边、仅文字 | 关闭、重播 |
| 危险态 | 珊瑚色描边或底 | 失败、清空 |

状态：hover 抬 1px、active 压下 1px 且阴影收窄；disabled 降到 45% 不透明度并禁用指针。

---

## 5. 角色头像与身份

- 头像：真实 glTF 立绘截取的方图（现成 8 张），圆角 12
- 身份三件套：**名字 / 性格标签 / 一句话座右铭**
- 性格用色条区分（稳健=绿、激进=珊瑚、精算=紫），不靠文字才认得出人

---

## 6. 任务卡（发单阶段主视觉）

四行结构，图标 + 标签 + 右对齐数值；奖励用 36px 金色主数字；底部一句"客户要什么"。

## 7. 政策卡（改规则阶段主视觉）

每条规则一张卡：规则名 / 当前值 / 拖动条 / **一句人话解释后果**（"税太高，居民可能买不起技能"）。
跑完之后在同一区域追加对照：谁的决策变了、钱去哪了。

## 8. 资源栏（顶栏）

`文明名 · 轮次 · 国库 · 居民数 · 税率`；数字等宽；只放 5 项，不再加。

## 9. 经济结果展示

三段式：**结果**（中标/到手）→ **归因**（谁的决策变了）→ **去向**（私人投资 / 公共研发 / 国库）。
颜色语义固定：绿=成长、金=钱、珊瑚=损失、紫=研究。

---

## 10. 落地顺序（第二关，按观感收益排序）

1. 角色卡与身份三件套（"不看数字也能认出谁是谁"）
2. 竞标演出（报价逐条出现 + 中标高亮）
3. 政策卡（含"后果一句话"）
4. 字体与数值的全局一致性（清理硬编码颜色/字号）

**不做**：不重写整个项目；不新增 3D 美术资产；不改经济引擎。
