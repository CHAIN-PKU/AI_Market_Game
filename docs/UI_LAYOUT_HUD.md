## 区域职责

### 顶部 TopBar

- 文明名（可编辑图标跳创建）  
- 总金币 / 国库（tooltip 分拆）  
- `Day x / 7`（Slice）或 `x / 30`（MVP）  
- 人口固定 8  
- 生产力：引擎 `metrics` 简化指数  

右侧：帮助、设置（音量、低性能、DEV classic 链接）

### 左侧 ActivityRail（默认展开，可 ← 收起）

**Tab：任务 | 事件**

- **任务：** 开放单、进行中、玩家模拟单（ escrow 标记）  
- **事件：** Playback 当前指针 + 历史（L2）；点击跳转到 3D 聚焦  

### 中央 Viewport

- `Canvas` 全宽填满中列  
- 点击地面取消选择  
- 点击 Agent/建筑 → 打开右侧 Details  

气泡（L1）：Canvas 上世界空间 `Html` from drei，最长 ~40 字，3s 淡出

### 右侧 DetailsDrawer

- 未选：收起或显示文明一句旁白  
- Agent：头像、能力、钱包、Skills、目标、最近事件、**公开决策**（L3）  
- 建筑：功能说明 + 当前相关任务  

### 底部 ControlDock

| 控件 | 绑定 |
|------|------|
| 暂停 | Playback pause |
| 单步 | 播放一条动画意图 |
| 跳过动画 | 清空队列，**不重算** state |
| 1x / 2x | playback speed |
| 下一轮 | `POST advance`（busy 时 disable） |
| 自动 | 定时 advance |
| 发任务 / 制度 / 商店 | 模态或侧滑，**不全屏挡地图** |

## 首屏 Landing（非 HUD）

全屏 3D 或静态主视觉 + 中心 CTA 三按钮；无顶栏数据。

---

## 创建文明屏

左右分栏：左表单，右 **制度三卡** 插画（2D 即可）；底部「开始」。

---

## Z-index

地图 0 · 气泡 10 · HUD 20 · 模态 30 · 向导 40

---

## `/classic`

维持现有 `App.tsx` 布局；入口仅链接，不重构。

---

## 响应式

Slice 不验收手机；`< 1280px` 时左栏默认收起，右栏覆盖式。
